# v2.1.0

This release fixes tint strength and ambient rendering, improves tab caching, and adds automated regression coverage.

## Fixes

- Tint strength applies once to the complete flat color and directional gradient. At 50%, half of the native workspace background remains visible, including with ambient spread enabled.
- Sidebar, page rim, and toolbar tint share consistent backdrop layers. Compact panels keep their native clipping, fullscreen removes the inset frame, and moving the sidebar updates the ambient gradient's position.
- Each tab retains its own sample. Tabs with the same URL can show different video frames or page states without borrowing each other's colors. Settled tab revisits still avoid content-process messages.
- Navigation, source-setting changes, document replacement, and hot reload reject stale samples. Background same-document routes refresh when selected.
- YouTube sampling checks whether Ambient mode is actually visible and responds to toggles while playback is paused. Hidden ambient elements fall back to ordinary page sampling.
- Sampling follows the visible viewport, respects the configured video polling interval, notices late stylesheet loads, and stops unnecessary work in hidden tabs or after video removal.
- Toolbar foreground selection uses contrast ratios, and ambient edges are limited to preserve text contrast. Cleanup removes listeners, timers, overlays, and modified inline styles without waking unloaded tabs.

## Validation

- 32 automated regression tests.
- Native Zen renderer checks across both sidebar positions and toolbar layouts, strengths 0/1/50/100, and spreads 0/100, plus sidebar relocation, compact mode, fullscreen styling, and teardown.
- A disposable-profile integration check through Sine's actual script loader and chrome package.

Real YouTube playback, native window materials, and Glance still need hands-on coverage. Directional ambient lighting approximates four edge colors; it does not reproduce YouTube's full blur effect. Sampling and rendering have a cost, and no new CPU/GPU benchmark is claimed.

Requires a working Sine installation. This release updates the mod; it does not repair a missing Sine loader.
